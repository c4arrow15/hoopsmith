# Hoopsmith

Read-only analytics for Yahoo Fantasy Basketball leagues.

## Planned features
- League dashboard: teams, rosters, standings, settings
- Player rankings based on each league's scoring categories
- Roster strength and weakness analysis
- Trade analyzer and waiver recommendations
- AI assistant that answers questions using the app's own analytics
- Yahoo account connection via OAuth 2.0 (read-only)

## Tech stack
Next.js + TypeScript, FastAPI (Python), PostgreSQL

## Status
In early development.

*Fantasy data provided by Yahoo Fantasy.*
